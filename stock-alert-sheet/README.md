# 📈 주식 알림 구글 시트

관심종목이 **목표가·손절가·급등락** 조건에 닿으면 텔레그램으로 알려주고,
코스피·코스닥 **시장폭(상승/보합/하락 종목 수)**을 매일 기록하는 구글 스프레드시트입니다.

| 기능 | 내용 |
|---|---|
| 관심종목 알림 | 장중(평일 09:00~15:30) 10분마다 확인, 같은 조건은 하루 1번만 알림 |
| 시세 | 구글 `GOOGLEFINANCE` (약 20분 지연) |
| 시장폭 기록 | 평일 오후 4시쯤 네이버 금융에서 상승·보합·하락 종목 수를 읽어 기록 |
| 시장폭 알림 | 코스피 상승종목 비율이 상단(기본 70%) 이상 또는 하단(기본 30%) 이하일 때 |

> ⚠️ 투자 판단의 참고용 도구입니다. 시세 지연·누락이 있을 수 있으며, 매매 책임은 사용자에게 있습니다.

---

## 설치 (약 10분)

### 1. 시트에 코드 붙여넣기
1. 새 구글 스프레드시트를 만듭니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 `Code.gs` 내용을 지우고 이 폴더의 `Code.gs` 전체를 붙여넣은 뒤 저장(💾)합니다.
4. 왼쪽 ⚙️ **프로젝트 설정 → 시간대**를 `(GMT+09:00) 서울`로 맞춥니다.
5. 스프레드시트 탭으로 돌아와 새로고침하면 상단에 **📈 주식 알림** 메뉴가 생깁니다.
6. **📈 주식 알림 → 처음 설정하기** 를 누릅니다. 처음 한 번은 권한 승인 창이 뜹니다.
   (“확인되지 않은 앱” 경고가 나오면 **고급 → (프로젝트 이름)으로 이동**을 누르세요. 본인이 만든 스크립트라 뜨는 경고입니다.)

### 2. 텔레그램 봇 만들기
1. 텔레그램에서 **@BotFather** 를 검색해 대화를 열고 `/newbot` 을 보냅니다.
2. 봇 이름을 정하면 **토큰**(`123456:ABC...` 형태)을 줍니다.
3. 방금 만든 내 봇과 대화를 열고 아무 메시지나 한 번 보냅니다. (안 보내면 봇이 나에게 말을 걸 수 없습니다)
4. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열면
   `"chat":{"id":123456789` 부분의 숫자가 **채팅 ID** 입니다.
5. **[설정]** 시트에 토큰과 채팅 ID를 입력합니다.
6. **📈 주식 알림 → 텔레그램 테스트 메시지** 로 확인합니다.

### 3. 관심종목 입력

| 시장 | 종목코드 | 종목명·현재가·등락률 | 목표가 | 손절가 | 급등락 기준(%) |
|---|---|---|---|---|---|
| `KRX` (코스피) 또는 `KOSDAQ` | 6자리 (예: `005930`) | 자동 | 비우면 검사 안 함 | 비우면 검사 안 함 | 예: `5` → ±5% 이상 |

종목명에 “종목 확인불가”가 뜨면 시장(KRX/KOSDAQ)이나 코드를 확인하세요.

### 4. 자동 실행 켜기
**📈 주식 알림 → 자동 실행 켜기** 를 누르면 끝입니다. 끄려면 **자동 실행 끄기**.

## 자주 묻는 질문

- **공휴일에도 동작하나요?** 평일·시간만 확인합니다. 공휴일에는 시세가 바뀌지 않아 대부분 알림이 오지 않습니다.
- **시장폭 기록에 “실패”가 뜹니다.** 네이버 금융 화면 구조가 바뀌면 읽지 못할 수 있습니다. 관심종목 알림은 영향이 없습니다.
- **알림이 너무 많아요.** 급등락 기준(%)을 크게 하거나 비워 두세요. 같은 종목·같은 조건은 하루 1번만 보냅니다.
